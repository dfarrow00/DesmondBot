# DesmondBot

A small Discord bot project focused on casino-style mini games using virtual currency.

## About

DesmondBot started as a fun side project for a small Discord community I am a part of.
We wanted simple casino-style games we could play in chat without real money, just for competition and fun.

## Features
- Casino-style games
- Virtual currency/economy system
- Leaderboard and player stats
- Automatic daily balance top-up for players with low balance
- Logging of bot activity and events

## Tech Stack & Libraries
- C# / .NET 10
- NetCord
- Sqlite
- Serilog

## Running the Bot Locally
To run this locally, make sure you have the .NET 10 SDK installed.

1. Clone the repository
2. Add your bot token to appsettings.json
3. Build and run the solution in Visual Studio or via the .NET CLI
